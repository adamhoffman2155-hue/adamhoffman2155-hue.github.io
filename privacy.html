Frieren Fern Uploader Privacy Policy

Effective date: October 27, 2026

Frieren Fern Uploader is a private application operated by Adam Hoffman for managing his own YouTube channel, Frieren's Fern. The application is used by the operator only; it is not offered to the public and has no other users.

What the application does

The application uses the YouTube Data API v3, authorized through Google OAuth 2.0, to upload custom thumbnail images to videos on the operator's own YouTube channel. That is its only function.

Information the application accesses

The application accesses only the operator's own Google account authorization and the operator's own channel data needed to set thumbnails. It does not collect, receive, store, or process personal information from any other person.

How information is handled

OAuth credentials are stored locally on the operator's own computer. They are never sold, rented, shared with third parties, or used for advertising or analytics. No user data is retained by the application beyond the credentials the operator uses to run it.

Revoking access

The operator can revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates its authorization.
